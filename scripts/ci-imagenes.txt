# Imágenes de registros públicos que usa CI, con su digest y sus espejos. Lo lee scripts/ci-pull.sh.
#
#   grupo  imagen (la que nombran compose.dev.yml y correr.sh)  digest ("-" si el tag se mueve)  espejos…
#
# - Con digest, la imagen se baja SIEMPRE por digest (`repo@sha256:…`): el registro que la entregue tiene que
#   dar los mismos bits, o el pull falla. Es el digest del índice multi-arquitectura (el que muestra
#   `docker buildx imagetools inspect <imagen>`); los espejos de abajo publican el mismo.
# - Los espejos se prueban en orden cuando el registro primario contesta mal (toomanyrequests, TLS, caída):
#   se escriben sin tag (el script usa el de la imagen). El primario es el que figura en la columna 2.
# - El grupo es la unidad de la caché de Actions (.github/actions/imagenes): `base` la usan los dos jobs de
#   base de datos; `storage` solo el de Storage. Cambiar este archivo cambia la clave de la caché.
# - Si cambiás una imagen en compose.dev.yml o en correr.sh, cambiá también esta fila:
#   scripts/check-ci-imagenes.sh lo comprueba en CI.
